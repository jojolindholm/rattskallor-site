# Rättskällor.se — project site

Static GitHub Pages landing page for [Rättskällor.se](https://app.rattskallor.se).

- `index.html` — the page
- `styles.css` — styles (same tokens as the app: ink/primary/hair, serif display, sans UI)
- `favicon.png` — copied from `rattskallor-app/public/icons/favicon_large.png`
- `.nojekyll` — serve the files as-is

Edit locally and push to `main`; GitHub Pages redeploys on every push.
